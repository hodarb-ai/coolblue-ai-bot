# Coolblue AI Customer Service Bot 🤖

A professional AI-powered customer service bot 
built for Coolblue Netherlands using Claude API.

## Features
- Bilingual support (Dutch & English)
- Handles orders, returns, and warranty
- Few-shot examples for consistent responses
- XML-structured system prompt

## Tech Stack
- Python 3.x
- Anthropic Claude API
- Prompt Engineering
  ## How to Use
1. Copy the system prompt from prompt.py
2. Open claude.ai
3. Paste the prompt and start chatting!

## Skills Demonstrated
- System Prompt Design
- Few-Shot Prompting
- Chain of Thought
- XML Tags
- Prompt Testing
